# 蝦霸 (ShopC) - 蝦幣自動化採集工具

這是一個基於 Android 的自動化工具，專為蝦皮直播間設計，旨在提高蝦幣採集的穩定性與效率。

## 核心特性
*   **影像增強辨識**：內建專屬的 **金色 (Gold)** 與 **白色 (White)** 增強濾鏡，有效對抗直播間各種雜亂背景。
*   **三路 OCR 管道**：同時處理原圖與兩套濾鏡後的圖像，實現 1:1 的精準文字提取。
*   **響應式懸浮窗**：實時顯示辨識狀態、目標門檻 (Goal)、即時金額 (CoinVal) 與倒數時間 (Time)。
*   **影像偵錯 (Image Debug)**：支援將濾鏡處理後的圖片直接存入相簿 (`ShopC_Debug`)，方便調教效果。
*   **智慧搜尋與回溯**：自動切換時段策略，並具備房間歷史記憶與回溯功能，減少無效滑動。
*   **防偵測設計**：隨機化點擊座標與貝茲曲線模擬真人滑動。

## 系統要求
*   Android 8.0+
*   無障礙服務 (Accessibility Service) 權限
*   螢幕錄製 (MediaProjection) 權限

更多詳細技術說明請參考 `System_Workflow.md`。
